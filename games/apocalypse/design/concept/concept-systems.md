# 概念原型：核心系統與敵方波次

[design](../README.md)｜[總覽](concept-overview.md)

**狀態**：概念草案，數值皆為佔位，未經使用者確認；未標「使用者」的決定皆為「預設，可改」。出處標記沿用原目錄（`[powers Pxx]` 等，見總覽）。

## 3. 核心系統（原作概念的規則化）

每項：定義／與 StS 不同／在隊伍中的意義。

### 3.1 源質
- 見 1.1：每次行動 +2、上限 3、不棄手牌、可透支（+沉澱）。「燒盡」牌：本場源質上限 −1 `[item pi088]`。「源質結晶」：敵人死亡掉落於格上，單位走過拾取 → 下次行動 +1 源質 `[item pi145]`。
- 不同：能量按行動而非回合回復；可用沉澱借；上限隨階位。
- 隊伍：各自的池；AI〔囤積〕會存源質。

### 3.2 聖痕與之路五階
- 階位 1 水銀／2 黃金／3 以太／4 星銻／5 賢者之石 `[lineages li001]`。每階聖痕給：被動、階位牌池、以太 +1 源質上限與 +2 SPD。
- **進階**只在儀式節點：材料（菁英／Boss 掉：災厄結晶、血仇結晶、未死火焰、孽物灰燼 `[adv ad005]`）＋相性檢定（沉澱 ≤5 安全；6–9 有 50% 失敗 → 永久侵蝕狀態 `[powers P07]`、`[adv ad090]`）＋分支（天問：山鬼／河伯、少司命／湘君 `[lineages li011]`）。進階後：換被動、移除 1 張低階牌、加 2 張新階牌。原型只到 3 階。
- 不同：局內職業升階且有分支、失敗風險與材料門檻；卡牌 + 升級保留作「熟練」。
- 隊伍：材料共用、給誰由玩家決定；AI 選分支（可覆蓋）。

### 3.3 代價：沉澱／侵蝕／凝固；修正值
- **沉澱（個人 0–10）**來源：透支、深淵牌、敵方沉澱攻擊、地獄格、進深度節點。門檻：3 侵蝕 I（牌庫隨機 1 張加「侵蝕」標記：打出 +1 沉澱，可淨化）；6 侵蝕 II（SPD −2、受深淵傷害 +25%、進階有失敗率）；10 凝固（永久離隊；若在戰中發生，變成敵方「凝固者」單位到戰鬥結束；歪曲度 +10）`[powers P10]`、`[adv ad104]`。戰後 −1、休息 −2。
- **修正值（隊伍）**來源：各聖痕的「天命條件」（例：天問「本場治療累計 ≥15」）`[adv ad076]`、`[item pi039]`（毀爐修正值不補天問）；菁英／Boss；事件。用途：進階門檻、威權牌啟動、3 點 → 一人沉澱 −2、5 點 → 一人本場無視門檻 `[powers P19]`。
- 不同：負向計數有不可逆終點，正向資源可對沖。
- 隊伍：沉澱個人、修正值共享；AI 的慎重軸與「深淵許可」決定隊員會不會自己把沉澱打高。

### 3.4 歪曲度（一局）
- 0–100。來源：威權牌 +5～15 `[powers P16]`、凝固 +10、事件。降低：存續院清理事件 −5、修正值。
- 階梯：25 每波多 1 個侵蝕種散兵；50 一般遭遇多一波；75 Boss 戰加召喚波；100 敗北。收益：深淵牌 +X%、材料掉落增加。
- 不同：難度是玩家局內用威權的結果。隊伍：共享帳本。

### 3.5 遺物
- 三類，都要「承載」到一名角色（3 槽，以太 +1）：**邊境遺物**（被動；部分有反噬 `[item pi086,pi139]`）、**聖痕遺物**（譜系鎖、更強；配對聖痕 → 刻印 `[item pi147,pi051]`）、**威權遺物**（變成 0 費「威權牌」進承載者牌庫，打出花修正值並 +歪曲度 `[item pi072,pi073,pi076]`）。
- 不同：有主人、譜系鎖、可打出的遺物。隊伍：分配＝間接控制 AI。

### 3.6 藥物
- 隊伍藥袋 3 格；使用免費（主角行動時，對任何單位）；每瓶有後患 `[powers P12]`。退轉藥可對昇華者敵人降階，或對自己退階重選分支 `[item pi042]`、`[adv ad020]`。部分藥有保存期限（N 場戰鬥）`[adv ad061]`。

### 3.7 秘儀（CTB 版）
- 主角打出「秘儀牌」→ 場上「架設中」狀態（持續到架設者下次行動開始，或 200 刻）。在此期間任一隊友行動時打出「獻儀」牌 → 完成並結算；逾時 → 架設者 +1 沉澱。
- AI 隊員看到架設中且手上有獻儀牌，會優先打（守護／囤積軸不影響；激進軸若估計直接攻擊更高分可能忽略——這是風險，可用「集火」指令抑制）。
- 敵方秘儀：Boss 架設場域（佔格障礙／全場 debuff），擊殺主持者瓦解 `[creature cr164]`。
- 不同：跨單位、跨時間軸的配合牌型。

### 3.8 神蹟刻印
- `聖痕（≥2 階）＋ 指定聖痕遺物` → 自動加 1 張刻印牌 `[item pi031,pi106,pi104]`。換聖痕若不在配方內則移除。每名原型角色 1 個配方（§5）。

### 3.9 配合標籤（取代回合內先後）
- 牌文「若自你上次行動以來，隊友對目標施加了 X」→ 看時間軸上兩次行動之間發生的事。〔框架假設〕需要每個單位記錄「上次行動刻」與一份事件日誌。

## 4. 敵方：波次編排

- **遭遇資料** = 棋盤尺寸 + 部署區 + 波次清單；每波 = 單位列表 + 進場格 + 登場等待。全滅即下一波；最後一波全滅勝利。獎勵按波數累計。
- **波間**：下一波登場等待 50 刻（錯開 20），玩家有約半次行動的緩衝；己方格擋不清空直到各自行動。
- **波內協同**只用「光環」（首領／薩滿型：相鄰友軍 +攻擊）與「召喚」；首領／士氣／前後排留待後續。
- **單位欄位**：HP、SPD、佔格、移動力、意圖（射程／形狀／傷害／附帶）、登場格。
- 數值係數（占位）：3 人隊 → 每波總 HP ≈ 單人 StS 同層 1.5 倍，兩波合計 ≈ 3 倍；每波同時 3–5 單位。
