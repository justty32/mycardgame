# 整局流程子工作流

[整局入口](../game-flow.md)｜[關卡設計](../level-design.md)

先在整局入口定義玩家旅程與狀態責任，再依需求落到開發順序或持久化政策。這裡的流程支援原創版本規劃，不替使用者決定題材或玩法。

| 子流程 | 負責範圍 |
|---|---|
| [最小可玩版本](vertical-slice.md) | 從產品契約、起局與最少內容到結算、再開的開發順序 |

單一節點內容交關卡流程；整個 run 的出口與存讀邊界由本層共同核對。既有單場測試只作基準，完整版本需依各子篇補齊實際轉移的證據。
