# 聲音子流程 — 從素材到事件與生命週期

[聲音入口](../audio.md)｜[核實分析](../../../../analysis/slay-the-robot/design/audio.md)｜[使用者邊界](../../common/user.md)

**何時用**：已收到具體聲音需求，要完成製作、引用、觸發、停止與驗證。
**何時不用**：只有主題構想而無採用要求，先整理需求；只修傷害規則回機制流程。

## Done when

交付檔含需求、來源／條件、母檔→遊戲檔映射、事件 owner、驗證命令與日誌位置；適用子流程的斷言結果存在，未驗聽感／匯出範圍明列。純文件更新有局部檢查結果，整合 owner 負責整體 strict lint。

## 流程

先寫 brief：用途、情緒、辨識優先級、觸發與取消、時長、循環、重疊、變體、bus、音量關係及無聲時的視覺替代。成功出牌、攻擊嘗試、扣血命中與被拒絕分開；重要資訊不能只靠聲音。工程可決定的規格由 agent 落實，未決核心主題不自行填入。

### 來源與製作共同契約

先盤點既有資產與當次可用工具。沒有音訊生成／合成／轉檔工具就記缺口，不把 imagegen 當聲音工具，也不安裝服務或建 MCP。生成素材記工具／模型版本、提示及原輸出；錄音／委託記製作者、使用範圍、改作與署名要求。框架或插件 MIT 不代替外來音檔的授權。

保留可編輯母檔、原始檔與遊戲用檔對應，穩定語意命名、小寫副檔名、明確變體編號。採用紀錄含路徑、來源、規格、處理步驟與 hash；同質清單超過 1 KB 依 [資料契約](../../common/data-files.md) 用資料檔，不複製成多張 md 表。

規格記實際編碼、採樣率、位元深度、聲道、時長、大小；短音可先評估 WAV，長曲評估 Ogg，但不是硬性規格。保留必要尾音、去除非預期前置靜音；轉檔不只改副檔名。記峰值、相對響度與同時疊加餘量，不把串流平台 LUFS 當遊戲硬標準，也不以 normalize 代替混音。

### 共同載入邊界

相對路徑包含 `external/audio/...`，相對 game 根／成品根，不是 JSON 目錄。FileLoader 使用 runtime 原檔 loader，不會由 `.import` 設定取得循環。WAV 強制不 loop；OGG／MP3 才接 loop 旗標，且快取只以 path 分辨，第一次載入會決定同路徑的 loop。缺檔會返回非 null 的 fallback，須檢查實例不等於 MISSING_AUDIO。

打包 res 資源與 external 原檔是兩條路；前者保存實際引用及匯入設定，後者核對 `exported` feature 與成品旁 external 複製。不曾做 export 就標未驗，不從本機載入成功推斷成品可用。

## 交接

交付素材與來源、每事件播放次數／時點、停止 owner、相容與驗證證據。一般接線缺口交工程 owner，不丟給使用者；聽感須另有授權。繼續接 [mixing](mixing.md) 的無聲驗證門檻，純文件工作不得為完成條件而試播。
