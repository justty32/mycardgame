# UI 子工作流

[UI 入口](../ui.md)｜[圖像素材](../art-assets.md)

UI 入口保存場景、狀態、輸入與生命週期的共同規則。本目錄提供需要跨 scene、theme、文字和測試的具體操作鏈。

主選單或結算改原創風格、加入繁中文字型與多尺寸時，使用 [選單、繁中文字型與多尺寸](menus-localization.md)。先核對狀態與返回目的地，再處理文案／字型、布局及測試耦合。

只是換卡圖時走圖像素材，改結算時機則走 [整局流程](../game-flow.md)。背景 handler、幾何與文字斷言各自記錄；視覺、實際輸入與聽感只能以對應證據驗收，目前桌面與視窗操作限制仍適用。
