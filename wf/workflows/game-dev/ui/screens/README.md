# UI 場景與用途 — 從玩家旅程交付整套畫面

[UI 入口與共同技術流程](../../ui.md)｜[完整場景整合](../../scene-pack.md)

**何時用**：需求是「做對話框／商店／獎勵／戰鬥介面」等完整使用情境，需把圖像、文字、資料、操作、聲音與動畫一起交付。

**何時不用**：已有畫面只修一個 theme／focus／字型問題，可直接用 [共同技術流程](../../ui.md#子流程導航)；事件成本、供貨、AI、路線與結算規則仍歸內容／關卡／整局。

## Done when

所選場景篇產出的規格與結果檔存在，包含玩家目的、實際 opener／資料 owner、整套元件和素材包、各狀態結果、cue／取消 owner、fixture 及未驗項；適用的專項檢查回傳預期結果；文件 lint 通過（見 [testing](../../../testing.md)）。

## 流程與場景選擇

各場景篇是該畫面**程式事實**（節點路徑、signal 鏈、資料 owner、退出／清理時機）的單一來源；美術動態與聲音子篇只連過來，補自己的時點與 owner。

<!-- wf-nav -->
| 玩家正在做什麼 | 完整畫面流程 |
|---|---|
| 出牌、選目標、理解敵人／頭目與回合 | [戰鬥 HUD 與卡牌](combat.md) |
| 閱讀事件、辨識角色、比較選項並進分支 | [對話事件](dialogue.md) |
| 看商品／價格並購買 | [商店](shop-rest.md) |
| 在營地選服務、選牌並返回 | [休息服務](rest-services.md) |
| 領獎勵、draft 挑牌、確認或略過 | [獎勵與選牌](rewards-selection.md) |
| 檢視牌堆、效果要求的選牌、手牌選牌 | [牌庫 VIEW／SELECT](card-selection.md) |
| 查看路線、辨識可達節點並前進 | [地圖](map.md)；[地圖 fixture](map-fixture.md) |
| 起局選角、暫停／設定、收藏／歷史與結算 | [選單與收藏](menus-collection.md) |

先選畫面及相鄰的前後目的地，再讀該篇的來源。完整畫面不是按鈕／文字等元素總和：要知道輸入何時被接受、效果何時完成、退出時哪些工作必須取消。每篇把已存在 consumer 與新設計分開；「資料有欄位」不視為已接畫面。沒有既定 UI 設計時的最小方案寫法見 [UI 入口](../../ui.md#先寫玩家任務與狀態)，整套契約欄位見 [scene-pack](../../scene-pack.md#以完整玩家任務開場)。

圖片與動態不能自己改遊戲資料；完成 cue 不能由普通 hover 或文字刷新冒充。場景 helper 的呼叫鏈與證據層級見 [verification](../verification.md)。

## 交接

將畫面規格交內容／UI／美術／音訊／動畫各 owner，只保留一份資料與完成契約；跨領域時序由 [完整場景整合](../../scene-pack.md) 收斂。多個場景共用元件可抽取，但不得拿共用元件清單取代本篇的整套旅程驗收。
