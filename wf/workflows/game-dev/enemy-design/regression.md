# 敵人的專項回歸與評量

[敵人設計](../enemy-design.md)｜[驗收分流](../validation.md)｜[卡牌評量](../card-evaluation.md)

**何時用**：敵人資料與意圖圖已寫好，要建立能跑到意圖週期的回歸，或比較改前改後的難度表現。

**何時不用**：還在定義角色與意圖圖，回 [敵人設計](../enemy-design.md)；整場敵群與池接線的驗收走 [戰鬥遭遇](../level-design/combat.md)。

## 回歸與評量

先用固定 seed、明確 HP 與最小牌組，通過真實的生成、意圖更新、回合及死亡入口。覆蓋首輪與至少一輪完整循環、每條分支、狀態加成下的預告／實傷、提前擊殺、戰鬥結束時仍排隊的效果；召喚物另驗空槽／佔用槽、召喚上限假設及只剩 minion 的結束條件。只直接呼叫 action 無法驗證意圖週期。

評量建議分單體與整個敵群：固定牌組／策略比較改前改後，記錄回合數、生命損失、攻防資源、被迫行動及失敗原因；再換起手、seed、低生命、不同構築及最壞組合。平均值之外保留極端樣本與樣本數，避免把一場可贏當成平衡證明。沒有現成的自動平衡器；策略模擬的結果只適用該策略。

依 [validation](../validation.md) 選 Smoke、Combat、兩種棋盤模式與本次專項；既有 Combat fixture 不包含所有自訂敵人、召喚或難度。隔離測試由當前 runtime owner 串行執行（操作邊界見 [user.md](../../common/user.md#桌面與程序邊界)）。預告辨識度、動畫時點與音效感知需要人工驗收，未執行時標為未驗。
