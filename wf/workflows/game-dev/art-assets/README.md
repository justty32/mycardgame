# 美術與動態素材子流程

[圖像入口](../art-assets.md)｜[製作事實](../../../../analysis/slay-the-robot/design/art-production.md)｜[整套畫面](../scene-pack.md)

**何時用**：已從 game-dev 分派美術、動畫或特效工作，需要由具體用途走到可接入的素材套件。**何時不用**：純 UI 排版回 [UI](../ui.md)；規則與傷害時機走 [mechanics](../mechanics.md)。

## Done when

所選用途流程的任務紀錄、實際產物與驗收證據存在；交付狀態分別列出方向、資產、接線、視覺及尚缺能力。跨領域依賴有檔案、owner 與下一步，不以未產出的資產填入完成欄。

## 流程

先問本次在做哪個完整使用面，而非只問 PNG 或動畫。選下表用途，取得實際 consumer、尺寸與狀態契約後，沿共同的風格／製作流程完成母稿、版本與輸出；回用途流程做專項接線驗收。整個畫面含互動、動態與聲音時，由 scene-pack 協調共同版本和事件，不以圖像包代替整套畫面。

## 交接

用途流程不複製共通資產清單：用同一份風格版本、來源與母稿／輸出紀錄，交接實際消費端與未實作項。動畫與特效另附時間／原點，UI 另附容器與互動約束。遵守 [使用者邊界](../../common/user.md)：目前不開 GUI、不做桌面／截圖或播放聲音；未授權的視覺／runtime 檢查留待驗，不借用其他任務的成功紀錄。
