# audio — 聲音製作與接線入口

[遊戲開發](README.md)｜[UI](ui.md)｜[內容](content.md)｜[驗收](validation.md)

**何時用**：製作或替換音效、音樂與環境音，調整事件觸發、循環、切換、混音、音量或靜音。
**何時不用**：聲音提示的傷害／回合規則交 [mechanics](mechanics.md)；原生崩潰依既有邊界，不在聲音任務順便調查。

## Done when

任務交付檔存在，含聲音 brief、採用素材與來源、事件／停止接線、實際驗證及未驗範圍；需要的子流程完成條件有證據，受影響文件檢查回傳 0。無聽音驗證時明列待聽項，不宣稱完整音訊驗收。

## 流程

由 [聲音子流程](audio/README.md) 先選戰鬥、對話、商店或獎勵／地圖／選單等場景聲包，再接音效、音樂／環境音與混音／設定技術；跨類別任務沿其共同交付順序完成，不把所有細節堆回本入口。先查 [實作核實](../../../analysis/slay-the-robot/design/audio.md)，區分既有能力、缺陷與本次才要實作的能力。

## 交接

聲音所需的新 action 與資料欄位交內容／機制流程；來源及引用同步分析，跨媒體時序交 UI／呈現任務 owner。當前禁止播放、桌面／視窗／焦點操作；純文件任務只查檔與文件，不啟動引擎。
