# 關卡設計子工作流

[關卡入口](../level-design.md)｜[整局流程](../game-flow.md)

關卡先確定玩家在節點中的決策與離開條件，再接入可到達的地圖。依本次修改的責任選子流程；組合任務可依序使用多篇，共同設計與交接仍回關卡入口。

<!-- wf-nav -->
| 子流程 | 負責範圍 |
|---|---|
| [戰鬥遭遇](combat.md) | 普通、精英與 Boss 的敵群、事件池、獎勵及驗收 |
| [非戰鬥節點](noncombat.md) | 對話選項、商店、休息、寶箱與離開／死亡路徑 |
| [地圖與幕](map-act.md) | 生成參數、路線、資源節奏、跨幕與可達性 |

單體敵人行為回 [敵人設計](../enemy-design.md)，跨新局、結算與續玩的產品流程回整局入口。各子篇的完成條件是實際任務的驗收契約；文件存在不代表對應遊戲內容已完成。
